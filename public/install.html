Add askmoina to your home screen for the full camera-first experience in a focused app window.

On iPhone or iPad, use Safari’s Share menu to add askmoina to your Home Screen.

How to install

iPhone / iPad

Open this page in Safari. Tap Share, choose Add to Home Screen, turn on Open as Web App if shown, then tap Add.

Android

Open this page in Chrome. Use the browser menu and choose Install app or Add to Home screen.

Desktop

When supported, use the install icon in your browser’s address bar or choose Install askmoina from the browser menu.

Your account is still required. Camera and microphone permissions are requested only when you start the live experience.
